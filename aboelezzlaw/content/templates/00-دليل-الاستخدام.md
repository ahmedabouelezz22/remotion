# دليل استخدام حزمة نماذج العقود

## قبل أن تبدأ

هذه النماذج **أدوات عمل لا عقوداً جاهزة للتوقيع**. كل عقد يخضع لظروف أطرافه ومحلّه
والقانون الواجب التطبيق عليه، ولا يوجد نموذج يصلح لكل حالة.

استخدم النموذج كنقطة انطلاق، ثم:

1. احذف ما لا ينطبق على حالتك — البند الزائد قد يُفسَّر ضدك.
2. املأ كل حقل بين قوسين معقوفين `[ ]`؛ فراغ متروك يعني بنداً معطَّلاً.
3. راجِع البنود المعلَّمة بـ **⚠️** فهي التي تتغيّر بتغيّر الحالة.
4. اعرض العقد على محامٍ قبل التوقيع إن كانت قيمته معتبرة.

## البنود التي لا يجوز حذفها

| البند | لماذا |
|---|---|
| تعريف الأطراف | عقد بلا تحديد دقيق للأطراف لا يُنفَّذ |
| محل التعاقد | الغموض في المحل يبطل العقد أو يجعله محلّ نزاع |
| المقابل وطريقة سداده | أكثر مصادر النزاع على الإطلاق |
| المدة والإنهاء | بدونها تصبح العلاقة مفتوحة بلا مخرج |
| تسوية المنازعات | يحدّد أين وكيف يُحسم الخلاف قبل نشوئه |

## الأخطاء الشائعة

**الخطأ الأول: نسخ بند من عقد آخر.** البند مصمَّم لسياقه؛ نقله إلى عقد مختلف ينتج
تناقضاً داخلياً يُضعف العقد كله.

**الخطأ الثاني: إغفال ترتيب الأولوية بين المستندات.** إن كان للعقد ملاحق، حدّد أيها
يعلو عند التعارض.

**الخطأ الثالث: شرط جزائي مبالغ فيه.** للقاضي سلطة تخفيضه إذا كان مبالغاً فيه أو نُفّذ
الالتزام جزئياً، فالمبالغة لا تزيدك حماية.

**الخطأ الرابع: الإعفاء المطلق من المسؤولية.** الشرط الذي يعفي من الغش أو الخطأ الجسيم
باطل. النصّ على استثنائهما يقوّي البند لا يُضعفه.

**الخطأ الخامس: شرط تحكيم غامض.** حدّد عدد المحكّمين ومقرّ التحكيم ولغته وقواعده، وإلا
تحوّل الشرط نفسه إلى محلّ نزاع مستقل.

## قائمة مراجعة قبل التوقيع

- [ ] بيانات الأطراف كاملة وصحيحة (الاسم، الصفة، السجل، العنوان)
- [ ] صفة الموقّع ثابتة بمستند (تفويض / سجل تجاري / توكيل)
- [ ] محل التعاقد محدّد تحديداً نافياً للجهالة
- [ ] المقابل ومواعيد سداده وأثر التأخير
- [ ] المدة وآلية التجديد والإنهاء ومهلة الإشعار
- [ ] المسؤولية وسقفها واستثناءاتها
- [ ] السرّية ومدتها بعد انتهاء العقد
- [ ] الملكية الفكرية لما يُنتَج أثناء التنفيذ
- [ ] القوة القاهرة وأثرها
- [ ] القانون الواجب التطبيق وجهة تسوية المنازعات
- [ ] عناوين الإخطار وآلية تغييرها
- [ ] عدد النسخ وتوقيع كل صفحة
