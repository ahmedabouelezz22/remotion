آخر تحديث: 2026-11-11 · الحالة: **مقترح ينتظر اعتماد المالك** — لم يُنفَّذ أي
ترحيل، ولم يُمسّ الموقع الحيّ `aboelezzlaw.com`.

هذا الملف يجيب عن ثلاثة أسئلة: ما المطلوب، أين نقف منه، وكيف ننتقل إلى
ووردبريس دون خسارة ما بُني. حالة التنفيذ الفعلية للكود في `STATUS.md`.

اسم المؤسسة المعتمد: **Law Firm Abo Elezz** (بالعربية: مكتب أبو العز للمحاماة).
اسم «Abo Elezz Global» مُستبعَد بقرار المالك.

### ج) قيود ملزِمة (لا تُتجاوز في أي مرحلة)

- لا وعد بخدمات «غير محدودة»، ولا إيحاء بترخيص في دولة ما لم يثبت.
- لا منشور قانوني ولا نموذج عقد يُنشر قبل مراجعة المالك واعتماده.
- لا مراجع ولا أحكام ولا شهادات ولا تقييمات عملاء مختلَقة.
- لا شراء ولا ترقية ولا التزام مالي دون موافقة صريحة على التكلفة.
- لا ترحيل هدّام: الموقع الحيّ لا يُستبدل قبل اعتماد المالك للنسخة التجريبية.
- الأسرار لا تُكتب في الكود ولا المحادثة؛ تُدخل في النموذج الآمن أو لوحة المزوّد.

## 2) تدقيق الوضع الحالي

| البند | الواقع |
|---|---|
| الموقع الحيّ | `aboelezzlaw.com` على **Hostinger Horizons** (مُتحقَّق من ترويسات الخادم) — ليس ووردبريس، ومحتواه لا يُدار من لوحة تحكّم |
| الكود الجديد | Next.js 15 في هذا المستودع — مُختبَر محلّياً (85 اختبار وحدة + 1,350 تأكيد تكامل ومتصفّح)، **غير منشور** |
| حسابات WordPress.com | موقعان على الخطة **المجانية** (`aboelezz1` و `aboelezzdotcom`) — لا تقبل إضافات ولا قوالب مخصّصة دون ترقية مدفوعة |
| خطة Hostinger | **غير معروفة بعد** — هل تتضمّن استضافة ويب تقبل ووردبريس؟ يُحسم بقراءة الحساب عبر API |
| Paymob | الحساب أُنشئ؛ مفاتيح الإنتاج وحالة التفعيل غير معروفة |
| مفتاح Resend القديم | مكشوف سابقاً ويُعدّ مخترَقاً — **إلغاؤه بيد المالك** من لوحة Resend |

**ما يُحمل إلى ووردبريس كما هو:** التصميم والهوية البصرية، النصوص بالعربية
والإنجليزية، كتالوج القطاعات والمجالات والخدمات، المنتجات والأسعار، ملفات
النماذج الاثني عشر، المقالات، وسياستا الخصوصية والشروط.

**ما يُستبدل بمكوّنات ووردبريس:** السلّة والدفع وروابط التحميل وحسابات
العملاء والاشتراكات ولوحة المالك — وكلّها مكتوبة يدوياً في Next.js الآن.
هذا هو الثمن الحقيقي للانتقال، ويقابله أن المالك يدير المحتوى بنفسه.

## 3) المعمارية المقترحة

**ووردبريس مستضاف ذاتياً على استضافة Hostinger القائمة** (لا WordPress.com):
تحكّم كامل في الإضافات والقالب وقاعدة البيانات، وبلا اشتراك إضافي إن كانت
الخطة الحالية تسمح.

| الطبقة | الاختيار | السبب |
|---|---|---|
| القالب | قالب مخصّص يُنقل من تصميم Next.js الحالي | الهوية نفسها دون قالب تجاري ورسوم تجديد |
| أنواع المحتوى | إضافة مخصّصة صغيرة تسجّل: قطاع، مجال ممارسة، خدمة، منشور مكتبة، فيديو | بيانات المالك لا ترتبط بقالب بعينه |
| العلاقات | خدمة ↔ قطاعات ↔ مجالات (متعدّد لمتعدّد) عبر تصنيفات | خدمة واحدة تظهر تحت أكثر من قطاع |
| المتجر | WooCommerce (مجاني ومفتوح المصدر) بمنتجات رقمية قابلة للتحميل | تسليم فوري بعد الدفع، وإدارة من اللوحة |
| الدفع | إضافة Paymob لـ WooCommerce + PayPal | يُتحقَّق من الإضافة الرسمية وتوافقها عند التثبيت |
| العضويات | منتجات اشتراك + إضافة عضويات | **الاختيار والتكلفة يُعرضان للموافقة قبل التثبيت** |
| اللغات | إضافة تعدّد لغات | يوجد خيار مجاني؛ يُحسم في المرحلة 1 |
| البريد | SMTP الاستضافة نفسها | يُغني عن Resend |
| الوكلاء | REST API الأصلي + كلمات مرور التطبيقات، بمستخدم دوره «مسودات فقط» | الوكيل يكتب مسودة ولا يملك النشر |
| الاعتماد | حالات ووردبريس: مسودة ← بانتظار المراجعة ← منشور، مع دور «مراجع» | النشر بيد إنسان مخوَّل |

لا إضافة مدفوعة ولا ترقية خطة تُنفَّذ قبل عرض سعرها والحصول على الموافقة.

## 4) خارطة الطريق

| المرحلة | المحتوى | معيار الانتهاء |
|---|---|---|
| **0 — التدقيق** (الآن) | قراءة حساب Hostinger: الخطة، المواقع، إمكان تثبيت ووردبريس | تقرير: ممكن بلا تكلفة / يحتاج ترقية بسعر كذا |
| **1 — الأساس** | ووردبريس على نطاق فرعي تجريبي، القالب، أنواع المحتوى، اللغتان | المالك ينشئ مقالاً وخدمة من اللوحة بلا كود |
| **2 — المحتوى** | ترحيل القطاعات والمجالات والخدمات والمقالات والصفحات | مطابقة العدد والمحتوى للمعاينة الحالية |
| **3 — المتجر والعضويات** | WooCommerce، المنتجات، النماذج الفورية، Paymob في وضع الاختبار، العضويات | شراء تجريبي كامل في sandbox وتسليم الملف |
| **4 — الإطلاق** | نسخ احتياطي، تحويل النطاق، إعادة توجيه الروابط القديمة | اعتماد المالك كتابةً، ثم التحويل |
| **5 — التكاملات** | API للوكلاء، CRM، واتساب، قواعد الأحكام والتشريعات، الأكاديمية | تُفصَّل بعد الإطلاق |

### اختبارات القبول (من التوجيه التنفيذي)

1. إنشاء مقال من اللوحة ونشره بلا كود.
2. إنشاء خدمة وربطها بقطاع ومجال ممارسة.
3. إنشاء منتج رقمي ورفع ملفّه.
4. إضافة فيديو.
5. إنشاء مسودة عبر API تظهر «بانتظار المراجعة» ولا تُنشر.
6. مستخدم بدور محدود لا يستطيع النشر ولا تغيير الأسعار.
7. نسخة احتياطية كاملة تُستعاد على نطاق آخر.

## 6) قرارات مطلوبة من المالك

1. اعتماد المسار: ووردبريس مستضاف ذاتياً على Hostinger (الموصى به).
2. رمز API لحساب Hostinger لإتمام المرحلة 0 (يُدخل في النموذج الآمن فقط).
3. اعتماد مزايا العضويات وأسعار الباقات غير المسعَّرة.
4. سعر النموذج المنفرد (المقترح 1,500 ج.م، والحزمة 12,000 ج.م).
5. «الباقة المميزة» للشركات تَعِد بـ«استشارات غير محدودة» و«مراجعة عقود غير
   محدودة» — وهذا يخالف قاعدة عدم الوعد بخدمات غير محدودة. المقترح: حدّ
   استخدام عادل مكتوب.
6. مراجعة النماذج الاثني عشر قبل بيعها على الموقع الحيّ.
7. ما المطلوب في المدونة (الجملة لم تكتمل).
