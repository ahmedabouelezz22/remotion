# ملفات المنتجات الرقمية

ضع هنا ملفات المنتجات القابلة للتحميل (PDF / ZIP / DOCX).

اسم الملف يجب أن يطابق حقل `file` في `src/content/products.ts` تماماً، مثال:

```
private/downloads/contract-templates-pack.zip
private/downloads/zakat-guide.pdf
```

## لماذا خارج مجلد public؟

أي ملف داخل `public/` يمكن تنزيله مباشرة بمعرفة رابطه — أي بلا دفع.
الملفات هنا لا تُقدَّم إلا عبر `/api/download` بعد التحقّق من رمز موقّع
محدود المدة يُصدَر بعد تأكيد الدفع.

## بديل: تخزين خارجي

لو كانت الملفات كبيرة، ارفعها إلى تخزين خارجي (Cloudflare R2 / S3 / Bunny)
واضبط `DOWNLOAD_BASE_URL` في متغيّرات البيئة. عندها يُعاد توجيه العميل
إلى المزوّد بدل تحميل الملف عبر الخادم.
