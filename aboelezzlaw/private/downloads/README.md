# ملفات المنتجات الرقمية

هذا المجلد **مُخرَج بناء** — لا تضع فيه ملفات يدوياً إن كان لها مصدر نصّي.

## ما يُبنى تلقائياً

`contract-templates-pack.zip` يُولَّد من `content/templates/*.md` بالأمر:

```bash
npm run build:downloads
```

ويُنفَّذ هذا الأمر تلقائياً ضمن `npm run build`، فتُبنى الحزمة عند كل نشر على Vercel.

**لتعديل نموذج:** حرّر ملف الـ Markdown في `content/templates/` ثم ادفع التغيير.
لا تحرّر ملفات `.docx` الناتجة — فهي تُستبدل عند كل بناء.

## ملفات تُرفع يدوياً

الملفات التي ليس لها مصدر نصّي (ككتاب PDF مصمَّم) تُوضع هنا مباشرةً باسم مطابق
لحقل `file` في `src/content/products.ts`، مثال:

```
private/downloads/zakat-guide.pdf
```

وحتى يُرفع الملف يبقى المنتج معلَّماً بـ `comingSoon: true` في الكتالوج، فيُعرض
بوسم «قريباً» ولا يُضاف إلى السلة ويرفضه الخادم عند الدفع. احذف العلامة بعد الرفع.

## لماذا خارج `public/`؟

أي ملف داخل `public/` يمكن تنزيله بمعرفة رابطه — أي بلا دفع. الملفات هنا لا تُقدَّم
إلا عبر `/api/download` بعد التحقّق من رمز موقّع تشفيرياً وصالح 72 ساعة.

## الملفات الكبيرة

للملفات التي تتجاوز بضعة ميجابايت، ارفعها إلى تخزين خارجي (Cloudflare R2 / S3)
واضبط `DOWNLOAD_BASE_URL` — عندها يُعاد توجيه العميل إلى المزوّد بدل تحميل الملف
عبر خادم الموقع.
